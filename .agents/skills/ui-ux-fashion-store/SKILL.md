# UI/UX Skill: Fashion & Apparel E-Commerce

Este Skill define las reglas obligatorias de diseño visual, experiencia de usuario y conversión para tiendas virtuales de ropa, moda infantil, calzado y accesorios.

## 🎨 Paleta & Tipografía
- **Fondo base**: Blanco puro `#ffffff` o crema claro `#faf8f5`.
- **Texto principal**: Grafito oscuro `#111827`.
- **Acento conversivo**: Rosa vibrante / Crimson (`#f43f5e` o `#ec4899`).
- **Insignias de descuento**: Fondo rosa suave (`#fff1f2`) con texto rosa intenso.

## 🛍️ Estructura de Secciones Obligatoria
1. **Barra de Anuncios**: Descuentos del día y envío gratis.
2. **Hero Banner**: Imagen limpia de modelo o prenda, título corto y 2 botones CTA.
3. **Parrilla de Productos**:
   - Selector de tallas (XS, S, M, L, XL).
   - Precios destacados en Soles (`S/ 89.90`).
   - Etiqueta de `% OFF` o `Nuevo`.
4. **Beneficios de Compra**: Algodón antialérgico, cambio de talla gratis, envíos el mismo día.
5. **Prueba Social (Testimonios de Mamás/Compradores)**: Calificación de 5 estrellas con reseñas verified.
6. **Botonera de Pedido Directo**: Botón flotante o directo de pedido por WhatsApp.
