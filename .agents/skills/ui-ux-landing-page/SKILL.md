# UI/UX Skill: High-Converting Landing Page

Este Skill define las reglas obligatorias de copywriting, secuencia narrativa y conversión para landing pages.

## 🚀 Secuencia Narrativa
1. **Hero**: Promesa de valor irresistible + Imagen/Video + Formulario o Botón CTA.
2. **Prueba Social**: Logos de clientes o prensa.
3. **Sección Problema vs Solución**.
4. **Matriz de Precios / Tarjetas de Planes**.
5. **Acordeón FAQ**.
6. **CTA de Cierre**.
