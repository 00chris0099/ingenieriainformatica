# UI/UX Skill: E-Commerce Store Standard

Este Skill define las reglas obligatorias de arquitectura web para tiendas e-commerce generadas en WMS Platform.

## 🎯 Reglas de Conversión
- **Precios Claras**: Mostrar precio regular tachado y precio de oferta relámpago.
- **Botón Principal**: `Comprar por WhatsApp` o `Añadir al Carrito` en color verde WhatsApp `#22c55e` o rosa rosa `#f43f5e`.
- **Garantías Visibles**: Íconos de seguridad de pago y entrega garantizada.
